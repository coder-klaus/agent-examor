## MODIFIED Requirements

### Requirement: Rich Markdown import editor

The admin import flow SHALL provide a **WYSIWYG** Markdown editor (primary editing surface without requiring split-pane source editing) with an optional source view, storing plain Markdown compatible with existing `### Q` / `### A` import rules.

#### Scenario: Operator edits import markdown

- **WHEN** the operator uses the import tab
- **THEN** they can format content with toolbar controls in a single visual surface and optionally switch to Markdown source
