## ADDED Requirements

### Requirement: Rich Markdown import editor

The admin import flow SHALL provide a split Markdown editor with live preview for deck import content, storing plain Markdown compatible with existing `### Q` / `### A` import rules.

#### Scenario: Operator edits import markdown

- **WHEN** the operator uses the import tab
- **THEN** they can edit in a toolbar-equipped Markdown editor and see rendered preview including code blocks and math where supported
